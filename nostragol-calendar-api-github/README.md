# Nostragol Calendar API

Backend seguro para crear eventos en el calendario Google Calendar de Nostragol.

## Comandos

```bash
npm install
npm start
```

## Render

Build command:

```txt
npm install
```

Start command:

```txt
npm start
```

Variables de entorno requeridas:

```txt
GOOGLE_CALENDAR_ID=nostragolapp@gmail.com
GOOGLE_CALENDAR_TIME_ZONE=America/Santiago
GOOGLE_SERVICE_ACCOUNT_KEY_BASE64=<secreto>
NOSTRAGOL_ADMIN_API_KEY=<secreto>
NOSTRAGOL_ALLOWED_ORIGINS=https://tu-backend.onrender.com,capacitor://localhost,http://localhost
```
